# 实验站多方言配置的无损迁移

此项目使用本地合成资料描述语言工具工程场景。`inputs/` 中的源文本、目录与事件只用于离线开发，不对应真实实验室、设备或研究结论。

## 资料契约

目录中 `dialect` 是显式提示，没有提示时需根据文件本身的可区分构造判定；两种方言都能合法解释时必须报歧义。`include` 使用工作区相对路径，别名、局部声明和内嵌 `${...}` 表达式参与绑定。源文本的注释、换行、字面量和未知扩展都属于无损编辑范围。迁移请求记录预览时的文件摘要，只有当解析和绑定前提仍成立时才可应用。

## 资料检查

使用 CPython 3.11 标准库，无需安装第三方包。资料检查会读取任意资料目录中的文本、JSON 与 JSONL，输出路径、文件大小和原始字节摘要。

```sh
python3 inspect_inputs.py inputs
python3 -m unittest discover -s tests -v
```

当前项目只提供领域资料、交换约定与资料清点入口；目标语言的编译、分析和运行能力尚未实现。
